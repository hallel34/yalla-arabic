# יאללה ערבית · يَلّا عَرَبي

אפליקציה בסגנון דואלינגו ללימוד **ערבית מדוברת פלסטינית**, עם אותיות ערביות מהשיעור הראשון.

## מה יש בה
- **מסלול:** 8 יחידות ו-25 שיעורים: האותיות, ברכות, משפחה, מספרים, שוק, דרכים, זמן ושיחה.
- **כל מילה:** כתב ערבי עם ניקוד, תעתיק עברי, תרגום והקראה.
- **סוגי תרגילים:** היכרות, בחירה מרובה לשני הכיוונים, הקשבה, הרכבת משפטים מאריחים, הקלדה (תרגום ותעתיק, עם סליחה על שגיאת כתיב אחת), דיבור עם זיהוי קול (בדפדפנים שתומכים), וכתיבת אותיות על קנבס.
- **תחושת משחק:** צלילי נכון/לא נכון, קונפטי בסוף שיעור, רצף תשובות נכונות (קומבו) עם בונוס נקודות, ובונוס על שיעור מושלם.
- **רצף ימים עם הקפאה:** כל 7 ימי רצף מעניקים "הקפאת רצף" שמכסה אוטומטית יום אחד של הפסקה.
- **חזרה חכמה:** כל מילה חוזרת אחרי יום, 3 ימים, שבוע, שבועיים, חודש וחודשיים. מילים שהתקשית בהן בשיעור חוזרות כבר באותו היום.
- **שיחה עם Claude:** תרגול מצבים מהחיים (שוק, מוסך, בית קפה). עובד רק בגרסה שנפתחת מתוך Claude.
- **ביחד:** מעקב משותף ויעד שבועי לזוג. עובד רק בגרסה שנפתחת מתוך Claude.

## הרצה
זה קובץ HTML אחד בלי תלויות ובלי שלב build. פותחים את `index.html` בדפדפן.

מחוץ ל-Claude ההתקדמות נשמרת ב-`localStorage` של הדפדפן.

## הקראה
האפליקציה בוחרת את הקול הערבי הטוב ביותר שיש במכשיר (עדיפות לפלסטיני, ירדני, לבנוני וסורי, ולקולות Natural/Neural), ומשמיעה אותו דרך Web Speech API. אם אין קול ערבי במכשיר, ההקראה עוברת אוטומטית לקול מהרשת (דורש אינטרנט). כפתור הרמקול בראש המסך בודק את הקול ואומר איזה קול נבחר. המילים, האותיות והמשפטים של הקורס מוקלטים מראש (קול ערבי ירדני עצבי, נוצר אופליין, מוטמע ב-`window.AUDIO` בתוך `index.html`), ולכן הם מושמעים בכל מכשיר וגם בתוך Claude, בלי אינטרנט ובלי קול במכשיר. רק טקסט חדש, כמו תשובות בשיחה, משתמש בקול המכשיר או ברשת.

## מבנה הקוד
הכול ב-`index.html`:
- `LETTER_INFO`, `UNITS`: תוכן הקורס. כל שורת מילה בנויה כך: `ערבית|תעתיק|עברית`.
- `buildLesson`, `buildReview`: הרכבת התרגילים.
- `srsHit`, `GAPS`: מנגנון החזרה המרווחת.
- `window.claude.use(...)`: יכולות שקיימות רק בתוך Claude (שמירה בענן, זהות, שיחה). מחוץ ל-Claude הן פשוט לא נטענות.


### מצבי קול
כפתור הרמקול בראש המסך מחליף בין ארבעה מצבים: אוטומטי (קול ערבי במכשיר אם יש, אחרת הקלטות), הקלטות, קול המכשיר, וקול גוגל מהרשת. כל ההקראות עוברות דרך `ttsText()`: כתיב פלסטיני (ق כ-א, ث כ-ת, ذ כ-ד) עם כל התנועות שקול של ערבית ספרותית צריך. בלי זה, למשל, خَمْسة נקראת "ח'מסת".

כלים בתיקייה `tools/`: `tts_texts.js` מפיק את רשימת הטקסטים, `check_pronunciation.py` משווה את ההגייה של הקול לתעתיק העברי, ו-`make_audio.py` מקליט מחדש את ההקלטות. הוראות בראש כל קובץ.
